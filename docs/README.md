## 4. 文档维护规则（小团队版）

| 规则 | 说明 |
|---|---|
| **改代码同 PR 改文档** | 行为变了，`architecture.md` / README 一起改；没改就是文档债 |
| **notes 只追加** | 历史记录不改写；新理解写新笔记 |
| **ADR 只增不改** | 决策变了就新增一条，旧条目标"已废弃" |
| **architecture 定期校** | 大改后（加模块、改端口、改调用链）必须更新 |
| **规范要短** | `conventions.md` 控制在 2 页内；能工具化的规则不写进去 |
| **不写"正确的废话"** | "代码要优雅"这种话不写；写"Controller 不写业务"这种可执行判断 |
